Wayfinding

Redesigning navigation and IA for an enterprise platform that grew organically—from chaos to user-centered structure

The Problem

No IA, no wayfinding

Dayforce had no information architecture. For years, product teams could add new pages whenever they wanted. The global nav became a dumping ground—too long, too nested, organized by org structure instead of user needs.

Users couldn't find anything. Navigation had 50+ top-level items, some nested 4-5 levels deep. No search. No breadcrumbs. No sense of "where am I?"

Org-Driven Structure
Nav reflected internal teams, not user workflows. "Payroll" separate from "Compensation" even though users needed both together.
Unbounded Growth
Any team could add a nav item. No governance. Nav grew to 50+ items, some nested 5 levels deep.
No Landing Pages
Click "Recruiting"—goes directly to candidate list. No overview, no dashboard, no context about what's in this area.
No Search
Users forced to remember where everything lived. Couldn't type "time off request" to find it quickly.
Solution

A complete wayfinding system

We didn't just redesign the nav—we built an entire wayfinding system including global nav, feature nav, omnibar search, and dashboard templates.

01 Global Nav
Primary navigation
Streamlined to 8-10 top-level "districts" organized by user mental models, not org structure. Collapsible, persistent left sidebar.
02 Feature Nav
Secondary navigation
Contextual nav within each district. Shows pages/features specific to current area. Tab-like pattern at top of content.
03 Omnibar
Global search
Cmd+K to search anything. Pages, employees, reports, settings. Autocomplete, recent items, quick actions.
04 Dashboard Template
Landing pages
Every Level 1 page gets a dashboard. Overview, quick actions, recent activity. Orients users before diving in.
Key Innovation

Organizing around "districts"

The biggest insight: Dayforce's IA reflected how we're organized internally, not how users think about their work.

We needed to group product areas in a way that matched user mental models—without alienating users who'd learned the old structure.

The Districts Approach
Instead of "Payroll" + "Compensation" + "Benefits" as separate silos, we grouped related areas into coherent districts based on user workflows.
District: People
Employee profiles, org charts, demographics, personal info
District: Pay
Payroll, compensation, bonuses, deductions—everything related to paying people
District: Time
Timesheets, schedules, time off, attendance—everything time-related
District: Talent
Recruiting, onboarding, performance, learning, succession planning
The Challenge
How do we reorganize without breaking existing users' muscle memory? We tested extensively, provided migration guides, and rolled out gradually to minimize disruption.
Navigation Architecture

Three-level hierarchy

L1
Districts (Global Nav)
8-10 top-level areas. Always visible in left sidebar. Click to enter district, see dashboard.
Example: People, Pay, Time, Talent, Benefits, Reports
L2
Features (Feature Nav)
Major features within a district. Shown in horizontal tabs at top of content area. Specific to current district.
Example: In "Pay" district → Payroll, Compensation, Bonuses, Deductions
L3
Pages (In-Feature)
Specific pages/views within a feature. Usually accessed via dashboard links or breadcrumbs. Not always visible in nav.
Example: Within "Payroll" → Pay Runs, Pay Calendars, Pay Groups
Search & Discovery

Omnibar: The escape hatch

Even the best IA can't predict every user need. The omnibar (Cmd+K) is the escape hatch—search anything, go anywhere, fast.

OMNIBAR (CMD+K)
RECENT
Employee: John Smith
Pay Run: Jan 2026
Pages
Jump to any page by name
Employees
Search by name, ID, email
Quick Actions
Create employee, run payroll
Landing Pages

Dashboard template for every district

Previously, clicking "Payroll" took you directly to a list. No context. No overview. Just data.

Now, every Level 1 district has a dashboard landing page that orients users before they dive into specific features.

Dashboard Anatomy
📊
Overview Cards
Key metrics, status summaries. "3 pay runs this month", "12 pending approvals"
⚡
Quick Actions
Common tasks. "Create employee", "Run payroll", "Submit time off"
🕒
Recent Activity
Last viewed employees, recent pay runs, draft reports
🔗
Feature Links
Navigate to major features within district. Alternative to feature nav tabs.
